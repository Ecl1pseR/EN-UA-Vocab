# EN-UA Vocab 🇺🇦🇬🇧

**EN-UA Vocab** — це розумний додаток для вивчення англійської мови, який інтегрується безпосередньо у ваш повсякденний досвід користування смартфоном. Замість того, щоб виділяти окремий час на навчання, ви вивчаєте нові слова кожного разу, коли просто перевіряєте час або сповіщення на екрані блокування.

![Kotlin](https://img.shields.io/badge/Kotlin-1.9-blue.svg)

## 🌟 Основні можливості

- **Навчання на екрані блокування**: Додаток автоматично показує нове слово при кожному пробудженні екрана.
- **Стиль "Медіа-плеєра"**: Керуйте словами прямо зі шторки сповіщень. Кнопки "Назад" та "Вперед" доступні навіть у компактному вигляді.
- **Розумна історія та Рандом**: Кнопка "Вперед" обирає нове випадкове слово, а "Назад" дозволяє повернутися до щойно побачених слів.
- **Імпорт власних словників**: Завантажуйте власні JSON-файли зі словами, які потрібні саме вам.
- **Менеджмент джерел**: Вмикайте, вимикайте або видаляйте словники в один тап.
- **Повна інформація**: Окрім перекладу, додаток показує рівень складності (B2, C1 тощо) та частину мови.
- **Оптимізація під Android 14**: Використання `Full Screen Intent` та `Foreground Service` для стабільної роботи на сучасних пристроях (тестовано на OnePlus 8T).

## 🛠 Технологічний стек

- **Мова**: Kotlin
- **UI**: XML / Material Design 3
- **Фонові процеси**: Foreground Service, Broadcast Receivers
- **Серіалізація**: GSON (для роботи з JSON словниками)
- **Архітектура**: Clean Data/UI separation

## 📂 Формат словника (JSON)

Для імпорту власного словника використовуйте наступну структуру файлу:

```json
[
  {
    "word": "abandon",
    "translation": "покинути",
    "level": "b2",
    "pos": "verb"
  },
  {
    "word": "benevolent",
    "translation": "доброзичливий",
    "level": "c1",
    "pos": "adjective"
  }
]
```

## 🚀 Як почати

1. Склонуйте репозиторій:
   ```bash
   git clone https://github.com/Ecl1pseR/EN-UA-Vocab.git
   ```
2. Відкрийте проєкт в **Android Studio**.
3. Зберіть APK та встановіть на пристрій.
4. Запустіть сервіс у додатку та надайте дозвіл на сповіщення.
